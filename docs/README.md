# Documentación de Tino

- `especificacion.md`: especificación de producto (qué hace la app).
- `documentacion-tecnica.md`: documentación técnica (cómo se construye).
- `progreso.md`: seguimiento del MVP por etapa, con casillas, pendientes y decisiones. Se edita en el repositorio, no en claude.ai.
- `maquetas/`: pantalla de inicio en modo claro y oscuro (HTML de referencia) y comparación del icono.

Estos archivos son copias exportadas de los documentos que se editan en claude.ai. Cuando cambie alguno de ellos, vuelve a exportarlo y reemplaza el archivo aquí, para que Claude Code trabaje con la versión vigente.
