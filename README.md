# Tino

App que le dice al usuario qué tarjeta de crédito usar hoy. Instrucciones para Claude Code en `CLAUDE.md`.

- `docs/`: especificación, documentación técnica y maquetas.
- `src/tipos/tipos.ts`: modelo de datos compartido.
- `src/motor/__tests__/motor.casos.json`: 17 casos de prueba del motor con resultados esperados.
- `herramientas/motor-referencia/`: implementación de referencia del motor en Python y generador de casos.
- `src/diseno/tokens.json`: paleta Jade y oro, tipografía, espacios y radios.
- `src/paises/do.json`: configuración de República Dominicana (feriados por completar).
- `src/i18n/es-DO.json`: textos iniciales en español dominicano.
- `datos-publicos/emisores-do.json`: catálogo de 40 emisores de RD (productos por completar).
- `assets/iconos/`: iconos de App Store, Google Play y capas del icono adaptativo de Android.
